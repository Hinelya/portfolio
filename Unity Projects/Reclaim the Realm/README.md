# Reclaim the Realm

A 3D third-person action combat prototype developed with Unity, where the player fights invading forces using melee and ranged weapons to liberate a devastated village.

## Game Overview
The player battles hostile invaders using swords and bows while navigating through a handcrafted medieval environment. Enemies patrol designated areas, investigate suspicious activity, chase intruders, engage in combat, and defend occupied territory.

The project focuses on implementing core gameplay systems commonly found in third-person action games, including character control, combat mechanics, enemy AI, patrol behaviors, weapon systems, and scene transitions.
